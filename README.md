## ✨ Key Features

- **Real-Time Messaging:** Instant message delivery powered by Firebase backend.
- **Secure Authentication:** User sign-up and login functionality via Firebase Auth.
- **Modern UI/UX:** A fast, responsive, and intuitive interface built entirely with Jetpack Compose.
- **Clean Architecture:** Implements MVVM and Dependency Injection for a scalable and maintainable codebase.

## 🚀 Roadmap

- [ ] **Bluetooth Messaging:** Support for peer-to-peer messaging via Bluetooth for offline environments.
- [ ] **Group Chats:** Create and manage chat rooms with multiple participants.
- [ ] **Media Sharing:** Capability to send photos, videos, and files.
- [ ] **Push Notifications:** Stay updated with real-time alerts for incoming messages.

## 🛠 Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/)
- **Backend:** [Firebase](https://firebase.google.com/) (Auth & Realtime Database/Firestore)
- **Dependency Injection:** [Hilt](https://developer.android.com/training/dependency-injection/hilt-android)
